# Personal Portfolio – Full Stack

A full-stack personal portfolio built with **Angular** and **Node.js** to showcase my profile, skills, experience, and projects. The portfolio includes a custom admin dashboard that allows me to manage and update website content dynamically without modifying the source code.

## Features

- **Dynamic Portfolio:** Display personal information, skills, projects, experience, and contact details.
- **Admin Dashboard:** Manage and update portfolio content through a dedicated dashboard.
- **Content Management:** Add, edit, and update website data whenever needed.
- **Projects Showcase:** Display projects, descriptions, technologies, source code, and live demos.
- **Skills Management:** Organize and update technical skills.
- **Responsive Design:** Optimized for different screen sizes.
- **RESTful API:** Backend API for handling data and connecting the frontend with the database.
- **Database Integration:** Store and manage portfolio data dynamically.

## Admin Dashboard

The portfolio includes an admin dashboard that provides control over the website content, allowing the admin to:

- Update personal information.
- Manage skills and technologies.
- Add, edit, and delete projects.
- Update about section and experience.
- Manage contact information.

All changes are reflected dynamically on the portfolio without manually modifying the frontend code.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sayedmohameddev/NTI-PROJECT_2.git
```

### 2. Backend Setup

```bash
cd backend
npm install
```

Configure your environment variables in a `.env` file, then run:

```bash
npm start
```

### 3. Frontend Setup

Open a new terminal:

```bash
cd frontend
npm install
ng serve
```
